# Two-PDF RAG with FAISS

Reads **exactly two text-based PDFs**, chunks each page, embeds with the free `all-MiniLM-L6-v2` model, saves a FAISS vector index + source metadata to `vector_store/`, and returns the **top 3 chunks across both PDFs** with PDF name, page, chunk number and cosine similarity score. Optional local answer generation uses Ollama.

## Requirements

- Python 3.10+ (tested with recent Python versions for syntax; packages are installed locally on your machine)
- Internet access on first run to download the embedding model
- Optional: [Ollama](https://ollama.com/) installed for answer generation

## Setup in VS Code or a terminal

```bash
python -m venv .venv
# Mac/Linux:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Put **your two PDFs** in a `documents/` folder (e.g. `documents/pdf1.pdf`, `documents/pdf2.pdf`). Then:

```bash
python rag.py documents/pdf1.pdf documents/pdf2.pdf --question "What are the main findings?"
```

To ask multiple questions interactively:

```bash
python rag.py documents/pdf1.pdf documents/pdf2.pdf
```

To also generate a grounded answer with citations (Ollama must be running; pull the model once with `ollama pull llama3.2`):

```bash
python rag.py documents/pdf1.pdf documents/pdf2.pdf --question "What do the documents say about risks?" --generate
```

## Pipeline

1. **PDF ingestion:** `pypdf.PdfReader` extracts text page by page.
2. **Chunking:** 130-word overlapping windows, 25 words of overlap, with source metadata.
3. **Embedding:** `sentence-transformers/all-MiniLM-L6-v2` generates normalized vectors.
4. **Storage:** `faiss.IndexFlatIP` saves vectors to `vector_store/index.faiss`; chunk text + metadata go to `vector_store/metadata.json`.
5. **Retrieval:** query embedding searches FAISS for the most similar 3 chunks.
6. **Optional generation:** local Ollama model receives only those 3 chunks in its prompt and is instructed to cite the snippets and abstain when unsupported.

Index reuse: on subsequent runs, if the two input files and indexing settings have not changed, the saved FAISS index is loaded rather than rebuilt. Changes to either PDF trigger reindexing.

## Notes

- Scanned/image-only PDFs will need OCR before this basic text-extraction code can work.
- Fewer than 3 chunks in both PDFs combined means fewer than 3 retrieval results.
- Cosine similarity is a relative ranking score, not a probability of correctness.
- Answers generated by an LLM may still be wrong; inspect the retrieved chunks and citations.
